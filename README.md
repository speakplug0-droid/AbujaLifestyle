# AbujaLifestyle

A new clean-build foundation for an online Nigerian open-world lifestyle game.

## Product direction
- Landscape-first mobile/browser gameplay
- Third-person 3D world
- Online multiplayer foundation
- In-game smartphone with internet and game services
- Cars, properties, jobs, stores and economy
- Player factions: Club/Gang, Police, EFCC-inspired enforcement, fictional federal investigation, Army and Bandits
- No family system
- No NPC population as the core social population

## Build philosophy
This repository is the new game. The previous prototype is not part of this architecture.

## First milestone
Playable landscape game shell, HUD, third-person camera, phone UI, basic world, and multiplayer transport.
